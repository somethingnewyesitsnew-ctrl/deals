Import local data into Supabase

This page reads the old deal-ledger:* data still sitting in this browser's local storage (from before the switch to Supabase) and uploads it into your database. It only sees data from this browser, on this device — if your data was entered on a different computer/browser, open this same page there instead.

Safe to click "Scan" as many times as you want. Import uses upsert, so re-running it won't create duplicates — but it also won't undo anything, so it's a one-way push.
