Import local data into Supabase

This reads the old deal-ledger:* data still sitting in browser local storage (from before the switch to Supabase) and uploads it into your database. Safe to run more than once — import uses upsert, so re-running won't create duplicates.

Option A — data entered on this exact page/browser

Option B — data entered somewhere else (a local file, an older URL, another browser)

Local storage is scoped per browser + per exact URL/file path — so if you ever opened this app by double-clicking the HTML file, or from a different folder/URL, that data lives in a separate bucket this page can't see directly. To bring it over:

  1. Open that copy of the app in a browser (the file, or old URL, where your deals actually are).
  2. Open DevTools (F12 or right-click → Inspect) → the Console tab.
  3. Paste this in and press Enter — it copies your data to the clipboard automatically:
copy(JSON.stringify(Object.fromEntries(Object.keys(localStorage).filter(k => k.startsWith('deal-ledger:')).map(k => [k, localStorage.getItem(k)]))))
